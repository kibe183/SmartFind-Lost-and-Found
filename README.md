# SmartFind – Smart Lost and Found Management System

## About the Project

SmartFind is a web-based Lost and Found Management System developed to help people report, search for, and recover lost belongings.

The system provides a central platform where users can report lost or found items, browse reported belongings, submit ownership claims, and track the progress of their claims.

Administrators manage the platform by reviewing and approving or rejecting submitted claims.

## Features

### User Features

* User registration and login.
* Report lost items.
* Report found items.
* Upload item photographs.
* Browse available lost and found reports.
* Search and filter reported items.
* Submit claims for found items.
* Track claim approval status.
* Access a personal user dashboard.

### Administrator Features

* Secure administrator login.
* Access to the admin dashboard.
* Review submitted ownership claims.
* Approve or reject claims.
* Manage the claim review process.

## Technologies Used

* **Frontend:** HTML, CSS
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment:** XAMPP
* **Version Control:** Git and GitHub

## Installation and Setup

1. Install XAMPP on your computer.
2. Clone or download this repository.
3. Move the project folder into the XAMPP `htdocs` directory.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open phpMyAdmin and create the project database.
6. Import the project's SQL database file, if included.
7. Configure your database connection in `database.php` using your local credentials.
8. Open your browser and visit:

   `http://localhost/lost_found/`

## Project Structure

The project contains PHP pages responsible for user authentication, reporting items, browsing reports, submitting claims, and managing the system.

## Project Purpose

The main goal of SmartFind is to make the process of recovering lost belongings easier, more organized, and accessible through a centralized online platform.
